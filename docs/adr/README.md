# Décisions d'architecture (ADR)

Une décision technique structurante par fichier, numérotée dans l'ordre d'écriture. Une ADR acceptée n'est pas
réécrite : une décision qui change fait l'objet d'une nouvelle ADR qui la remplace. Les ADR à écrire et l'étape
qu'elles précèdent sont listées dans [PLAN-API](../plans/PLAN-API.md#adr-à-écrire-docsadr).
