## 2. Écrans de la tranche

Convention : « fixture existante » = nom déjà dans `apps/web/e2e/fausse-api/ecrans/*.ts` ; « nouvelle » = à créer au §3. Chaque test porte une étape `test.step("REC-PAR-nnn · …")` par scénario, projet `bureau` et projet `mobile` (360 px), axe à chaque état (`expectAccessible`). Le rendu serveur est partout le même : le front Next.js lit l'API depuis son serveur (`getServerApi()`), les écrits partent du navigateur (`apiCall`) ; la fausse API HTTP sert les deux.
